<p>In this challenge, we practice implementing <em>inheritance</em> and use JavaScript <em>prototypes</em> to add a new method to an existing prototype. Check out the attached <em>Classes</em> tutorial to refresh what we've learned about these topics.</p>

<p><strong>Task</strong></p>

<p>We provide the implementation for a <em>Rectangle</em> class in the editor. Perform the following tasks:</p>

<ol>
<li>Add an <em>area</em> method to <em>Rectangle</em>'s prototype.</li>
<li>Create a <em>Square</em> class that satisfies the following:
<ul><li>It is a subclass of <em>Rectangle</em>.</li>
<li>It contains a constructor and no other methods.</li>
<li>It can use the <em>Rectangle</em> class' <em>area</em> method to print the area of a <em>Square</em> object.</li></ul></li>
</ol>

<p>Locked code in the editor tests the class and method implementations and prints the <em>area</em> values to STDOUT.</p></div></div></div></div>
